Installer Deadline Breaker sur Mac

English

macOS 10.15 (Catalina) ou plus récent, Mac Intel ou Apple Silicon (M1 à M4). Environ 2 minutes.

  1. Ouvrir l'image disque

    Double-cliquez sur le fichier Deadline Breaker_…_universal.dmg. Une fenêtre s'ouvre avec l'icône de l'application et le dossier Applications.

  2. Copier l'application

    Glissez l'icône Deadline Breaker sur le dossier Applications. Fermez la fenêtre, puis éjectez le disque « Deadline Breaker » (bouton ⏏ dans la barre latérale du Finder).

    Lancez toujours l'application depuis le dossier Applications, jamais depuis l'image disque.

  3. Première ouverture : autoriser l'application (une seule fois)

    L'application n'est pas encore signée par Apple : macOS demande donc une confirmation à la première ouverture. C'est normal.

    macOS 15 Sequoia et plus récent

    • Dans Applications, double-cliquez sur Deadline Breaker. Au message « Apple n'a pas pu confirmer que… », cliquez sur Terminé (et non sur « Placer dans la corbeille »).
    • Ouvrez Réglages Système › Confidentialité et sécurité, descendez jusqu'à la rubrique Sécurité : « Deadline Breaker a été bloqué… ». Cliquez sur Ouvrir quand même, saisissez votre mot de passe, puis confirmez Ouvrir quand même.

    macOS 14 Sonoma et versions antérieures

    • Dans Applications, faites un clic droit (ou Contrôle + clic) sur Deadline Breaker, choisissez Ouvrir, puis Ouvrir dans la fenêtre de confirmation.

    Les ouvertures suivantes se font normalement (Launchpad, Dock, Spotlight).

  4. Autorisations demandées ensuite (normales)

    • Dossier Documents : cliquez sur Autoriser. Les exports et sauvegardes y sont rangés (dossier « Deadline Breaker »).
    • Trousseau : à l'enregistrement d'une clé API, « Deadline Breaker souhaite utiliser… » : saisissez le mot de passe de votre session puis cliquez sur Toujours autoriser. Les clés sont ainsi protégées par macOS et ne figurent jamais dans les fichiers de l'application.
    • Lancement automatique (Paramètres › Alertes e-mail) : macOS affiche « Élément d'arrière-plan ajouté ». C'est le réglage que vous venez d'activer ; il se retire en décochant la case.
Message « Deadline Breaker est endommagé et ne peut pas être ouvert » ?

Cela peut arriver lorsque le fichier a transité par certaines messageries. L'application n'est pas abîmée : ouvrez le Terminal (Applications › Utilitaires), collez la ligne ci-dessous, validez avec Entrée, puis relancez l'application.

xattr -dr com.apple.quarantine "/Applications/Deadline Breaker.app"

Mise à jour

Refaites les étapes 1 et 2 et choisissez Remplacer. Dossiers, paramètres et clés sont conservés. macOS peut redemander une fois l'accès au Trousseau : Toujours autoriser.

Désinstallation

Glissez Deadline Breaker d'Applications vers la Corbeille. Les données du cabinet restent sur le Mac dans ~/Library/Application Support/LexProcedura (à supprimer seulement si vous voulez tout effacer, après une sauvegarde).

Installing Deadline Breaker on a Mac

Français

macOS 10.15 (Catalina) or later, Intel or Apple silicon Mac (M1 to M4). About 2 minutes.

  1. Open the disk image

    Double-click Deadline Breaker_…_universal.dmg. A window shows the app icon and the Applications folder.

  2. Copy the app

    Drag Deadline Breaker onto Applications, close the window and eject the "Deadline Breaker" disk (⏏ in the Finder sidebar). Always start the app from Applications, never from the disk image.

  3. First launch: allow the app (once)

    The app is not yet signed by Apple, so macOS asks for confirmation the first time. This is expected.

    macOS 15 Sequoia and later

    • Double-click Deadline Breaker in Applications. When "Apple could not verify…" appears, click Done (not "Move to Bin").
    • Open System Settings › Privacy & Security, scroll to Security: "Deadline Breaker was blocked…". Click Open Anyway, enter your password and confirm Open Anyway.

    macOS 14 Sonoma and earlier

    • In Applications, right-click (or Control-click) Deadline Breaker, choose Open, then Open again.

  4. Permissions asked afterwards (expected)

    • Documents folder: click Allow (exports and backups go to "Deadline Breaker").
    • Keychain: when an API key is saved, enter your login password and click Always Allow. Keys are protected by macOS and never stored in the app's files.
    • Launch at login (Settings › E-mail alerts): macOS shows "Background item added". Untick the box to remove it.
"Deadline Breaker is damaged and can't be opened"?

This can happen when the file went through some messaging services. The app is fine: open Terminal (Applications › Utilities), paste the line below, press Return and start the app again.

xattr -dr com.apple.quarantine "/Applications/Deadline Breaker.app"

Updating

Repeat steps 1 and 2 and choose Replace. Matters, settings and keys are kept.

Uninstalling

Drag Deadline Breaker from Applications to the Bin. Firm data stays in ~/Library/Application Support/LexProcedura.
